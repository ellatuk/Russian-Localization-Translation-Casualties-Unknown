Локализация выполнена вручную, с учётом стилистики игры и оригинального текста.  
Я стараюсь подходить к переводу, сохраняя смысл оригинального текста и используя возможности русского языка, а не gogal translate copy paste
А как выходит, так выходит :)

В переводе мне помогает музыка, словари, личный опыт и зелёный чай.
